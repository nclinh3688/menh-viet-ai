# Mệnh Việt AI - Project Overview

Mệnh Việt AI là website định hướng khám phá bản thân qua AI, Tử Vi, Ngũ Hành,
Hôn Nhân, Thần Số Học và Phong Thủy.

## Sprint 1

Sprint này chỉ khởi tạo nền tảng kỹ thuật:

- Next.js App Router
- TypeScript
- Tailwind CSS
- shadcn/ui-ready component structure
- Prisma với SQLite cho môi trường dev
- Zod và React Hook Form dependency
- ESLint và Prettier

## Ranh giới

- Chưa tích hợp AI API thật.
- Chưa tích hợp thanh toán thật.
- Chưa triển khai thuật toán tử vi/phong thủy.
- Nội dung tử vi/phong thủy phải luôn đi kèm cảnh báo:
  "Nội dung chỉ mang tính tham khảo và khám phá bản thân."
