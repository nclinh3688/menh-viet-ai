# Birth Report Quality Audit

## Mục tiêu

Birth Report v1 phải được kiểm tra để bảo đảm nội dung:

- đúng theo dữ liệu có sẵn;
- không tự bịa;
- không dùng từ tuyệt đối;
- dễ hiểu;
- có giá trị thực tế;
- đáng tin cậy;
- đúng văn phong Mệnh Việt.

## Rule kiểm tra chất lượng

File:

- `/lib/quality/content-quality-checker.ts`

Checker quét text trong `ReportRenderModel`, bao gồm:

- overview;
- key insight;
- interpretation;
- strengths;
- cautions;
- career;
- finance;
- relationship;
- health;
- recommendations;
- why reasons;
- source explanations;
- disclaimer.

## Từ cấm

Checker báo warning nếu gặp:

- chắc chắn
- sẽ
- định mệnh
- 100%
- tuyệt đối
- đại họa
- phá sản
- ly hôn chắc chắn
- AI diễn giải
- AI phân tích
- generated by AI

## Section bắt buộc

File:

- `/lib/report-engine/report-validator.ts`

Validator kiểm tra report có đủ:

- overview
- rawData
- keyInsight
- interpretation
- strengths
- cautions
- recommendations
- sources
- disclaimer

Nếu thiếu, dev panel hiển thị `Missing sections`.

## Source requirement

Mỗi kết luận quan trọng trong `why` phải có:

- sources;
- reason;
- confidence.

Nếu thiếu, dev panel hiển thị `Missing sources`.

## Confidence warnings

Validator báo warning khi:

- `why.confidence < 60`;
- `overview.confidence < 60`;
- confidence bị thiếu hoặc nhỏ hơn/equal 0.

## Development Debug Panel

Trong `/birth-report`, nếu `NODE_ENV === "development"`, cuối trang hiển thị:

- Report quality status;
- Missing sections;
- Forbidden words found;
- Missing sources;
- Confidence warnings;
- Other warnings.

Production không render panel này.

## Cách test report

1. Chạy `npm run dev`.
2. Mở `/birth-report?profileId=<id thật>`.
3. Cuộn cuối trang để xem `Development Quality Debug`.
4. Kiểm tra không có forbidden words.
5. Kiểm tra sources/reasons/confidence không thiếu.
6. Chạy `npm run build` để xác nhận production build không lỗi.

## Những phần còn thiếu

- Chưa có automated tests cho checker/validator.
- Chưa có CI quality gate.
- Chưa có scan toàn app cho copy ngoài report.
- Chưa có source registry đầy đủ để tăng độ tin cậy.
